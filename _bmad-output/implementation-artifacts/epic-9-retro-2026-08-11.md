## What went well

1. **The 9-1 foundation paid off exactly as designed.** 9-2 and 9-3 consumed `cash_config` + the additive `cash_states` fields with zero rework — the "model → math → action" story split held.
2. **The loop is a genuine force multiplier.** Once unblocked, it built two non-trivial money-path stories (yield-aware math; a durable liquidation/pending-buy state machine) that passed their ACs and full suites.
3. **The adversarial review harness paid for itself.** It caught a real-money guardrail bypass (SELL-scope widening + verbatim `/approve` trust) and a user-facing honesty contradiction (▼ "loss avoided" beneath "the market rose") that the loop's own review missed.
4. **Honesty discipline held.** The 4% money-market APY was a *disclosed*, named placeholder — not hidden; no-red/no-FOMO enforced by copy tests.
5. **Test isolation protected real money.** The disposable `ballast_test` database kept MasterB's live Schwab `brokerage_token` safe through dozens of suite runs (the documented go-live gotcha never bit).

## What didn't / challenges

1. **The loop's self-review is insufficient for money-path work.** Both 9-2 and 9-3 shipped with `followup_review_recommended: true`; the independent pass found 8 real issues — **2 of 3 stories** needed post-hoc fixes, one touching real money. *(MasterB's #1 takeaway.)*
2. **Honesty bugs travel in twins.** 9-2's "key market-direction on `window_return`, not the dollar sign" was fixed in the backend statement during the loop's review — but the identical bug survived in the frontend glyph/label until the independent review. Fixing one side didn't fix its mirror. *(MasterB's #2 takeaway.)*
3. **Loop-built money-path code merged to `main` before the independent review.** Recoverable (fake-broker, caught quickly), but the guardrail gap was briefly on `main`.
4. **`bmad-loop tui` "showed nothing"** — a cwd trap: it defaults `--project` to the current directory, and it was launched from `ballast/backend` while the project root (holding `.bmad-loop/runs`, sprint-status, deferred ledger) is the repo root. Not a bug; a usage gotcha now recorded.

## Patterns across stories

- **`followup_review_recommended: true` on every loop-built money-path story (2/2).** A reliable signal: this class needs an independent gate.
- **Honesty/framing defects recur across the stack.** The same "sign-of-dollar vs market-direction" bug appeared backend (fixed) and frontend (missed) in 9-2.
- **Disclosed-but-untuned placeholder constants keep accruing** (8.4 suggestion heuristics → 9-2's 4% APY). Consistently handled honestly, but the tuning backlog grows.
