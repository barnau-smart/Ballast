## Intent

**Problem:** Stories 10-1..10-3 answer "deploy my idle cash toward my target," but that is only half a portfolio review. A beginner also needs to know when they are over-concentrated in one speculative position or bleeding money to a needlessly expensive fund — and be handed the concrete fix. Today nothing flags single-name concentration or high fees.

**Approach:** Add two deterministic, read-only **analysis buckets** alongside the existing deploy engine, each producing a concrete SELL-side action item that is narrated by the 10-3 advisor safeguards and populated (never submitted): **(1) concentration/single-stock** — a non-index-core holding whose weight exceeds the concentration ceiling → a TRIM SELL back toward the ceiling (de-speculate into the diversified index core, reusing the 9-3 sell-sizing/OrderIntent primitives); **(2) cost/fees** — a held fund whose expense ratio materially exceeds its near-identical cheaper same-class canonical index fund → a SWITCH (SELL the high-fee holding; the follow-up BUY of the cheaper fund is narrated, the tax consequence noted honestly but NOT computed). A new small **expense-ratio reference table** supplies the fee facts. A new read-only `GET /api/allocation/review` returns the ranked findings each with its narration; the coach console lists each as a CoachCard and populates the selected finding's SELL order.

## Boundaries & Constraints

**Always:**
- **Never invent a fact.** Every number a finding's narration states (trim/switch dollar amount, holding market value, holding weight, the concentration ceiling, both expense ratios) comes from the deterministic detectors / the expense-ratio reference table and is in the finding's numeric allow-set. Reuse the 10-3 gates verbatim: `validate_recommendation` (reasoning non-empty, ≥1 uncertainty, ≥1 cited engine evidence id) **plus** `check_no_invented_numbers(text, allowed)` **plus** `check_no_forecast(text)` over `reasoning + action_label + *uncertainties`. **Any** rejection / gateway / parse failure (and fake-LLM mode, whose unbacked evidence id fails `validate_recommendation`) degrades to a deterministic `_fallback_review_narration` — never a dead-end, never a surfaced unvalidated fact.
- **Expense-ratio values are real published net expense ratios.** The reference table IS the fee-fact source; a wrong value would poison the never-invent gate. Use accurate public figures (they are stable public facts). Unknown symbols have no entry → no cost finding (never invent a ratio).
- **Opinion, not forecast.** Narration opines on the user's situation and settled principles (diversify; minimize costs); the no-forecast gate rejects prediction language. No market forecasts, ever.
- **"Nothing to do" is valid.** Zero findings → the endpoint returns `{"findings": []}` with **no LLM call**; the UI shows a calm "nothing to fix" message. A non-index single stock **under** the ceiling produces no action (aware-but-don't-act is deferred, per epic).
- **Populate, don't submit.** The endpoint places nothing and writes no `decision_record`; it reads the cached portfolio read-only. Each finding carries a typed `order` (SELL, MARKET) the human co-signs through the existing `/approve` spine. Whole-share sizing (reuse `whole_share_quantity`); a trim/switch that sizes to < 1 whole share is dust → dropped.
- **Rebalance/de-speculate, never chase; calm/no-FOMO; suite green.** Concentration targets single-name risk in **non-index** holdings only — a broad index-core position over the ceiling is asset-class balance handled by the deploy/rebalance path, not trimmed here. Money is `Decimal` → fixed-point wire strings (`format_money`, no exponent); per-user scoped (AD-10). All new copy passes the digest FORBIDDEN-word bar. Each finding's fallback passes the **5 good-lesson tests**. Backend `pytest` (`ballast_test` DB) + frontend `vitest` stay green.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Concentrated single stock | non-index holding weight > ceiling (e.g. TSLA 55% of a portfolio) | one `kind="concentration"` finding: `order` = SELL MARKET of `market_value − ceiling×total` (whole-share floored); narration de-speculates into the index core; number ∈ allow-set | LLM path; fallback on any gate/gateway failure |

| Both buckets fire | over-concentrated stock AND a high-fee fund | ≥2 findings, ranked by SELL dollar amount desc (ties by symbol asc); each narrated + independently populatable | per-finding fallback |

## Design Notes

**Additive by design — don't touch the deploy engine.** The BUY-centric `Plan`/`narrate_plan`/`/plan`/`/narration` are frozen (10-2/10-3 suites depend on them). This story is a parallel SELL-side review path (`allocation/review.py` + `GET /api/allocation/review`) that only IMPORTS the 10-3 gate helpers. This keeps the never-invent/no-forecast machinery single-sourced while isolating regression risk.

**Concentration rule (why non-index only).** Single-name risk is what a trim addresses. A broad index-core fund over the ceiling is asset-class concentration, which the deploy/rebalance path already corrects by buying the underweight classes — trimming a healthy diversified core would be perverse. So the trim bucket fires only for a **non-index-core** (`is_index_core` false), non-parked holding whose weight > `CONCENTRATION_CEILING` (reuse the coach 0.40 ceiling; mirror locally with a comment if not cleanly importable). Weight = `market_value / (Σ holding market_values + cash)`. Trim amount = `market_value − ceiling × total`, then whole-share floored (`whole_share_quantity`, unit price = `market_value / quantity` from cache, mirroring `cash/liquidation.py`); < 1 share → dust, dropped. A non-index stock **under** the ceiling is intentionally left alone — "aware-but-don't-act" is a deferred epic item, and we never manufacture a trade.

**Cost/switch rule.** For a held fund with a table entry `(er, asset_class)`, the near-identical cheaper index fund is `CANONICAL_FUND[asset_class]` (a broad low-cost core fund) whose ER is looked up from the same table. Fire a `cost` finding when `held_er − canonical_er ≥ EXPENSE_RATIO_MATERIAL_DELTA` (0.20pp default — a beginner-meaningful gap that compounds over decades). The SELL leg (whole position, whole-share floored) is populated; the follow-up BUY of `switch_to` is narrated as step two (funded by the sale) and the tax consequence is noted honestly ("selling may realize a taxable gain; we don't calculate tax here") but NOT computed — matching the epic's tax deferral. Index-core/canonical funds never trigger (they are the cheap target). Unknown funds have no ER → no finding (never invent).

**Narration mirrors 10-3's deploy branch exactly.** One STRATEGY `EvidenceRecord` per finding (statement names the holding + the concrete SELL amount; `stats` holds the raw `Decimal`s; `make_id` content-addressed). `allowed_review_facts` admits the SELL amount, holding market value, weight (fraction e.g. `0.55` AND percent `55`), the ceiling (both forms), and both expense ratios (as percents) — value-compared via `Decimal`, exactly as 10-3. Fake-LLM mode self-heals: its placeholder cites an unbacked id → `validate_recommendation` raises → `_fallback_review_narration`, so fake mode yields real templated copy for free.

**Fallback copy (per kind), authored to pass the 5 lesson tests:** concentration → principle: a single company is speculative vs the diversified core; tradeoff: you cap the upside of one name but cut single-name risk; recognized best practice: diversification; uncertainty: markets move, a fill isn't guaranteed, this isn't a prediction. cost → principle: low costs compound; tradeoff: selling may realize a taxable gain (noted, not computed); recognized best practice: minimize fund fees; uncertainty: same honest hedge. All numbers drawn only from `allowed_review_facts`; calm-word-list clean.
