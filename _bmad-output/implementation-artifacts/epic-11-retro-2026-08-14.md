## What went well

1. **The pipeline held end-to-end** — fiduciary consult → epic framing (`epics.md` Epic 11) → per-story `create-story` → (money-path) `bmad-spec` + MasterB approval → `dev-story` → independent review → commit. No shortcuts, no specless money-path work.
2. **The mandatory independent-review gate caught a real defect in 4/4 stories** and confirmed the money-path story (11-2) has no oversell / double-spend / order-placement path. The builder's own "green" was never trusted as sufficient for the review module.
3. **Money-path spec-approval gate worked** (11-2): the 4 decisions + the partial-cash residual rule were approved before any code.
4. **Coverage-object reuse** — 11-1's `Coverage` powered 11-3 and 11-4 with minimal new code and zero divergence (one sleeve, three framings).
5. **Honest scoping** — the fiduciary consult was constrained to real data + guardrails, yielding a buildable catalog AND an explicit "cannot honestly do" list (tax-loss/asset-location/factor/vol). Nothing was faked. 11-3/11-4 were right-sized to informational-only, keeping them off the money path.

## What was hard / lessons

1. **Recurring non-finite `market_value` defect (the headline lesson).** Fixed in 11-1 (inside `compute_coverage`), it RE-APPEARED in 11-2 because the finite-guard lives at *call sites* (`compute_coverage`, `_total_portfolio_value`, concentration detector, `_deployable_parked`) — NOT in the shared `classify_holdings` (`engine.py:189`). Independent review caught it both times. Every new consumer of `classify_holdings` must remember to filter; one forgot. → root-cause fix (Action #1).
2. **Wrong tool at first** — `bmad-create-epics-and-stories` (greenfield regenerator) was wrong on a mature `epics.md`; caught and switched to per-story `create-story` + an appended epic section. Lesson: for a mature project, append + per-story, never regenerate.
3. **Redundant portfolio reads** — `/review` now fetches the cached portfolio up to 4× (`build_review` / `build_coverage` / `build_fees` / `build_plan`). Perf-only (cached), but worth consolidating.
4. **Story 10.14 reconciliation** — 11-2 superseded 10.14's bond-shortfall scope; its equity-overweight (both-directions drift) generalization is deferred. Needs to be formally marked so it's never built unreconciled.
