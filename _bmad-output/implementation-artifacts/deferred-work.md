  summary: The digest claim uses claim-execute → send → commit, so a `session.commit()` failure AFTER `sender.send()` already succeeded rolls the claim back (un-marks the user), and the next run re-sends — a sequential commit-failure double-send that re-opens the NFR8 never-nag guarantee the concurrent claim closes.
