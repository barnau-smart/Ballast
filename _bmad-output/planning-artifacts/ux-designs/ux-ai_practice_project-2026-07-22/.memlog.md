- (decision) UX NORTH STAR = anxiety-reducing: every screen/interaction must lower decision-anxiety, never raise it. Behavioral success framing (consistency, staying the course), NOT returns. Capture-not-beat language throughout.
- (decision) UX invariants (from PRD §8/NFR8): always surface the WHY (reasoning) + explicit uncertainties — never a bare verdict; precedent shown as real drawdown data ('drops this size recovered in ~median 2mo'), never event-classification; PULL not push (on-demand, zero unprompted FOMO/opportunity alerts); coach VOICE = patient/warm/honest/plain teacher (first-class design concern); no-confident-call routes reassuringly to the default plan, never a dead-end.
- (decision) v1 flows to design: onboarding + Schwab link (surface ~weekly re-auth gracefully), plain-English portfolio, core coach loop (ask -> propose w/ reasoning+precedent+uncertainties -> approve/decline -> execute), regret-defusers (recovery-precedent view, decision co-sign at approval, decision replay after a dip), just-in-time teaching; SHOULD: missed-growth meter + headline contextualizer; optional calm weekly EMAIL digest. Responsive web app, React SPA. v1 scope only (no deferred features).
- (decision) THEMING: token-based from day one — DESIGN.md defines look as tokens (CSS variables: color/type/spacing/radius); components read tokens, never hardcode. A theme = one token set; multiple selectable themes possible; swapping a theme is cheap (no rebuild). Resolves the synthwave-vs-marketing tension: v1 can be synthwave, a calm 'market' theme is a later swap.
- (decision) v1 VISUAL DIRECTION (user's vision): 80s synthwave / old-school-computer (retro terminal) feel with a restrained Stranger Things hint. Tuned toward the CALM end of that palette (quiet CRT glow + muted neon accents, not aggressive neon); scary-moment screens (recovery-precedent, replay) kept visually calm. Rationale: personal-first product — delight drives the engagement/consistency that IS a success metric; tone/microcopy carries anxiety-reduction more than color does. Reversible via token themes.
- (decision) Visual direction refined (v2): darker/moodier Stranger-Things neon — near-black blue bg (Upside-Down), stronger neon glow, HERO neon RED (ST Benguiat-serif wordmark w/ subtle flicker) + cold-cyan contrast. KEY RULE: red = BRAND/identity only, NEVER used for loss/down. Market semantics use cool tones (teal=up, muted indigo=down) so losses are never shown in panic-red — reclaiming red as calm brand glow is on-mission for anxiety-reduction. amber = honesty/uncertainty.
- (decision) LOCKED visual direction = v2 (Stranger-Things neon). Promoted mockups/coach-card-direction.html as the reference. Now distilling DESIGN.md (tokens + spec) + EXPERIENCE.md (IA/voice/flows/states/a11y).
- (change) Visual reconsideration (v3): user second-guessed scanlines (distracting) + wants classic 80s GREEN-PHOSPHOR terminal look. Resolution — role discipline: GREEN terminal owns the interface (data/labels/short 'system' lines/chrome, > prompt, blinking cursor); ST RED neon is RARE brand punctuation only (wordmark + primary co-sign action); coach PROSE stays soft-white body font (green mono fatigues for long reading); scanlines DROPPED (readability + a11y) — soft CRT glow + vignette instead; market up=green / down=amber (both authentic terminal phosphors, never red). More cohesive + distinctive than generic synthwave. Pending user reaction to v3.
